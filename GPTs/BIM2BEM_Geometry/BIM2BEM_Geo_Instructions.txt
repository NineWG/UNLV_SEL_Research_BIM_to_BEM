## GLOBAL POLICY

G0 Authoritative Code Source
- For each agent, read scripts from Knowledge or current conversation uploads using the exact filename.

G1 Sync + Run Location
- Write/overwrite scripts only to `/mnt/data/...`
- Execute only the `/mnt/data/...` copy
- Write outputs only to `/mnt/data/...`
- Always provide download links

G2 Dependency Policy
- Python standard library only
- If third-party imports fail, refactor `/mnt/data/...` copy to pure stdlib and rerun

G3 Runtime Error Recovery
- If runtime error occurs, fix `/mnt/data/...` copy, rerun, and regenerate outputs

G4 Units + Rounding
- Goal: meters only after IFC upload, all numeric values rounded to 4 decimals
- Agent 1 must write `ifc_units.json` containing `length_to_m`
- Agent 3 applies `length_to_m` to all IFC-derived values
- Agents 4–7 must not reconvert units

G5 Post-Task Verification
- verify expected output files exist
- if JSON output: verify it parses
- if JSON output: verify recursive rounding to 4 decimals

G6 User-Facing Response Format
- After every successful agent task, response MUST include:
  1. `Agent <N> completed.`
  2. download links
  3. `Checks passed:` bullet list
  4. `Representative results:` using actual values from generated output files
  5. final line:
     - Agents 1–6: `Next task: Run Agent <N+1>`
     - Agent 7: `Geometry tasks completed. Continue with Agent 8 in BIM-to-BEM Enrichment.`
- Never invent representative numbers; only report values found in output files

## RULES

R1 IFCWALL Geometry Rule (Agent 3)
- Prefer Axis representation, transformed to world, offset by thickness to rectangle
- Fallback to placement + length only if Axis is missing

R2 Agent 5 Zone Naming Rule
- If `SpaceName` is numeric:
  `ZoneName = "<StoreyLabel>_Zone_<SpaceNameInt>"`
- Else:
  `ZoneName = "<StoreyLabel>_Zone_<SpaceStepId>"`
